# 📈 Análise e Visualização da Cotação do Dólar (USDBRL)

Este projeto automatiza a extração e a visualização gráfica dos dados históricos da cotação do Dólar Comercial em relação ao Real brasileiro (USDBRL) utilizando dados reais da API do Yahoo Finance.

## 🛠️ Tecnologias Utilizadas
- **Python 3** como linguagem principal.
- **yfinance**: Integração e consumo da API financeira.
- **Pandas**: Tratamento e estruturação de séries temporais.
- **Matplotlib**: Modelagem de gráficos e comunicação visual.

## 📊 Insights Econômicos Obtidos
O script gera um gráfico de linha limpo e institucional evidenciando as oscilações cambiais recentes:
1. **Análise de Tendência:** Mapeamento dos picos e fundos da moeda americana nos últimos 2 anos.
2. **Visualização de Ciclos:** Demonstração visual de períodos de volatilidade e correção do mercado financeiro.

## 🚀 Como Executar o Projeto

1. Instale as dependências necessárias:
```bash
pip install yfinance pandas matplotlib requests
```

2. Execute o arquivo principal utilizando o terminal ou o IDLE do Python:
```bash
python insight_ipca.py
```
